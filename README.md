# RV CME patient-level multiple-instance learning

This repository contains the final code and reproducibility package for patient-level classification of concurrent cystoid macular edema from fluorescein angiography in retinal vasculitis.

See [`Root/README.md`](Root/README.md) for the analysis design, environment, execution commands, released outer-test predictions, metric recalculation procedure, supplementary model-selection records, internal benchmark results, and fold-specific checkpoints.

The final `patient_mil_v1` reproducibility package contains no clinical images or original patient identifiers. Files elsewhere in this pre-existing repository are legacy materials and are not part of the final analysis described in the manuscript.
